Namun, pembuatan fungsi seperti ini tentu terasa redundan apabila kita akan menyapa pengguna dengan pesan “Selamat Datang” pada mayoritas waktu.

Oleh karena itu, Kotlin menyediakan Default Argument. Yaitu, cara untuk menetapkan nilai bawaan (default) dari sebuah parameter. Dengan Default Argument, sebuah parameter yang tidak diberikan argumen oleh pemanggilnya akan menggunakan nilai bawaan sebagai nilainya.

Lebih lanjut, Default Argument dapat dibuat dengan cara menginisialisasi parameter dengan nilai bawaan yang diinginkan. Contohnya seperti berikut.
